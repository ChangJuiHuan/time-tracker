# 24 小時時間紀錄 Web App

這是一個可以放到 iPhone 主畫面的簡單時間紀錄 Web App。

## 功能

- 睡覺、吃飯、洗澡、運動、讀書、娛樂六種活動
- 點選活動後開始計時
- 切換活動時自動結束上一個活動
- 今日統計
- 今日詳細紀錄
- 修改/刪除紀錄
- CSV 匯出
- 資料存在目前裝置的瀏覽器 localStorage

## 部署到 GitHub Pages

1. 到 GitHub 建立一個新的 repository，例如 `time-tracker`
2. 上傳本資料夾裡的所有檔案
3. 到 repository 的 Settings → Pages
4. Source 選 Deploy from a branch
5. Branch 選 main，資料夾選 `/root`
6. 儲存後等待 GitHub Pages 產生網址

## iPhone 加到主畫面

1. 用 Safari 打開 GitHub Pages 網址
2. 點分享按鈕
3. 選「加入主畫面」
4. 之後就能像 App 一樣從主畫面打開
